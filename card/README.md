# Ninad Watve — GitHub Pages digital visiting card

A deliberately minimal, static digital visiting card for `ninadhw.github.io`.

## Publish

1. Extract the ZIP.
2. In your existing GitHub Pages repository, create a folder named `card`.
3. Upload the contents of this package's `card` folder into that folder, preserving `assets/`.
4. Commit to the branch and publishing directory already used by your Pages site.
5. Visit `https://ninadhw.github.io/card/`.

Do not replace your existing homepage or change its Pages settings.

## Contact file

The page has one link: **Save contact**, which directly opens/downloads `contact.vcf`.
The vCard currently contains only the known name, Ninad Watve. Edit `contact.vcf`
as plain text to add verified contact details before publishing.

## Design

- Solid black background and white typography.
- Tenor Sans from Google Fonts, with a sans-serif fallback.
- White NW pencil monogram.
- Static HTML and CSS only; no JavaScript, forms, analytics, tracking, or interactive widgets.
- No build process or server required.

If Google Fonts cannot load, the page falls back to the browser's sans-serif font.
